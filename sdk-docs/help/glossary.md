description: "Terms used across the Android SDK docs"
order: 26
---

| Term                       | Meaning                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| AAR                        | Android Archive — the packaged library format you depend on from Maven                     |
| IRKit                      | Entry object for initialize / configuration                                                |
| IREngine                   | Recognition engine instance passed into IRKitLens                                          |
| IRKitLens                  | Compose scanner UI — where the camera lives; hosts preview, recognition, and match results |
| IRKitLensActivity          | Sample host Activity pattern (not a shipped library class)                                 |
| ImageModelShared           | Stable client match model via `toShared()`                                                 |
| ProductLinkShared          | Product on a shared match                                                                  |
| ProductInCampaignDto       | Product payload on `onProductClicked`                                                      |
| irkit-releases             | Public Maven host for generic client AARs                                                  |
| API key / subscription key | Credential passed to `IRKit.initialize`                                                    |
