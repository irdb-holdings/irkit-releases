Defines the visual style of the back button.

```swift
enum IRCameraBackButtonStyle
```

## Enumeration Cases

### IRCameraBackButtonStyle.arrow

Shows a left-facing back arrow.

```swift
case arrow
```

### IRCameraBackButtonStyle.close

Shows a close (X) icon.

```swift
case close
```

### IRCameraBackButtonStyle.none

Hides the back button.

```swift
case none
```
